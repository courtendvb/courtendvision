概要
----
CourtEnd Vision は、バレーボールアナリスト向けの
オーバーレイツールです（Windows / macOS 対応）。
画面に映るバレーボールコートの上に透視補正済みのグリッドを
重ねて表示し、ゾーン別のデータ入力をサポートします。

グリッドは常に最前面に表示されます。コーナーハンドル以外の
部分はクリックがそのまま下のアプリに透過します。


動作環境
--------
- Windows 10 / 11（64 ビット）
- macOS 12 Monterey 以降（Apple Silicon / Intel）
- 解像度不問


起動方法  —  Windows
---------------------
1. ZIP ファイルを任意のフォルダに展開します。
2. 「CourtEnd Vision.exe」をダブルクリックして起動します。
3. タスクバー右下のシステムトレイに緑色の丸いアイコンが
   表示されます。
4. 画面に白いグリッドが重なって表示されます。


起動方法  —  macOS（重要: 初回起動の手順）
-------------------------------------------
本アプリは Apple の公証（Notarization）を取得していないため、
macOS の Gatekeeper がブロックすることがあります。
以下のいずれかの方法で起動してください。

  【方法 A】右クリックで開く（最も簡単）
    1. ZIP を展開し、「CourtEnd Vision」フォルダを開きます。
    2. 「CourtEnd Vision.app」を右クリック → 「開く」を選択。
    3. 警告ダイアログで「開く」をクリックします。
    4. 2 回目以降はダブルクリックで起動できます。

  【方法 B】ターミナルコマンド
    ターミナルを開き、以下を実行してからアプリを起動します：
      xattr -cr ~/Downloads/"CourtEnd Vision"/"CourtEnd Vision.app"

  【方法 C】システム設定から許可
    1. アプリを開こうとします（ブロックされます）。
    2. システム設定 → プライバシーとセキュリティ を開きます。
    3. 下にスクロールし、CourtEnd Vision の横の
       「このまま開く」をクリックします。

初回起動後はメニューバー（画面右上）にアイコンが表示され、
画面に白いグリッドが重なって表示されます。


コートへのフィッティング
------------------------
グリッドの四隅に丸いコーナーハンドルが表示されます。
各ハンドルをドラッグして、映像上のコート四隅に合わせます。

  - ハンドルにホバー: カーソルがグラブハンドに変わります。
  - クリック＆ドラッグ: 好きな位置に移動できます。
  - ドラッグ中にグリッドがリアルタイムで追従します。

ヒント: コートのサイドラインとエンドラインの交点に
        ハンドルを合わせてください。


タスクトレイメニュー
--------------------
Windows: トレイアイコンを右クリック
macOS:   メニューバーアイコンをクリック

  Show Grid / Hide Grid（表示 / 非表示）
      グリッドの表示を切り替えます。

  Grid Color（グリッドの色）>
      White（デフォルト）/ Black / Red / Yellow / Green / Blue

  Opacity（透過率）>
      20% ～ 100%

  Zone Numbers（ゾーン番号）
      各セルに 1〜9 のゾーン番号を表示 / 非表示。

  Sub-zones（サブゾーン）>
      Off           - サブゾーン非表示
      Grid Only     - 点線の区切り線のみ（文字なし）
      Grid + Labels - 点線 ＋ A / B / C / D ラベル表示

  Settings...（設定）
      設定ウィンドウを開きます。

  Quit（終了）
      アプリを終了します。


設定ウィンドウ
--------------
トレイメニュー → 「Settings...」で開きます。

  Grid Color（グリッドの色）
      カラーピッカーで色を選択。

  Opacity（透過率）
      スライダーで 10% ～ 100% の間で調整。

  Line Width（線の太さ）
      グリッド線の太さ（1〜8 px）。

  Zone Numbers（ゾーン番号）
      トグルスイッチで表示 / 非表示。

  Sub-zones（サブゾーン）
      Off / Grid Only / Grid + Labels の 3 択。

  Reset Corners（コーナーをリセット）
      四隅のハンドルをデフォルト位置（画面中央付近）に戻す。

  Apply（適用）
      変更内容をすぐに反映します。

  Close（閉じる）
      設定ウィンドウを閉じます。


グリッドのレイアウト
--------------------
コート全体（両サイド）を 3 列 × 6 行 ＝ 18 マスに分割します。

ゾーン番号（手前カメラ側から見た配置）:

  奥バック   |  1  |  6  |  5  |
  奥ミドル   |  9  |  8  |  7  |
  奥フロント |  2  |  3  |  4  |
  ──────────── ネット（破線） ──
  手前フロント|  4  |  3  |  2  |
  手前ミドル  |  7  |  8  |  9  |
  手前バック  |  5  |  6  |  1  |

中央の破線がネット位置を示します。


サブゾーン（A / B / C / D）
----------------------------
各マスを点線で縦横に 2 分割し、計 4 つのサブゾーンに分けます。

  手前側（上から 4〜6 行目）:
      C | B
      ─────
      D | A     （A = 右下、B = 右上、C = 左上、D = 左下）

  奥側（上から 1〜3 行目）— プレーヤー視点で反転:
      A | D
      ─────
      B | C     （A = 左上、B = 左下、C = 右下、D = 右上）


その他
------
- コーナー位置・色・透過率などの設定は自動的に保存され、
  次回起動時に復元されます。
- 本ツールは映像・音声の録画や取得は一切行いません。
- グリッドが表示されない場合: メニュー → Show Grid を確認。
- Windows: アイコンがトレイに表示されない場合は再起動。
- macOS: アイコンがメニューバーに表示されない場合は再起動。
